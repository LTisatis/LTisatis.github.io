实现
每位角色 5 张透明 WebP：固定主体、两组头发、抬起的袖子、手掌与袖口。手掌嵌套在手臂组内。
外层原有入场与鼠标视差不变；内层 CSS transform 负责局部动作。没有增加动画库或逐帧 JavaScript 循环。
安奈发梢周期 4.6/5.2 秒，单侧转动幅度 1.5/1.8 度，挥手周期 18 秒。
索尼娅发束周期 5.4/6.2 秒，单侧转动幅度 1.7/2.2 度，挥手周期 23 秒。
手掌最大转动 6 度，手臂 1.2 度；两位角色首次挥手延迟分别为 4/11 秒，避免同步。
相较最初方案采用更保守的幅度，索尼娅暂未单独拆前额发束，以减少图层并保持脸部稳定。
肩部与袖口都留有底层重叠。脸与可见服装采用原图像素，补画仅用于移开手臂后露出的区域。
系统减少动态：静态原始姿态。手动暂停与后台：冻结当前姿态。手机、省流量且无明确偏好：默认静止。
正常加载不请求原 PNG；某角色任意分层图失败时，仅该角色切回原 PNG。

资源与性能
原两张 PNG：1,872,584 字节。
新 10 张 WebP：417,590 字节（约 418 KB），减少约 77.7%。
按各图裁切后宽×高×4估算，解码像素约 15.22 MiB；原两张图约 12.00 MiB，增加约 3.22 MiB。
以上是原始像素估算，不是实际 GPU 显存读数；屏幕分辨率与浏览器合成会影响显存。
新增 CSS 源文件 gzip 765 字节、角色控制 TS 源文件 gzip 681 字节；这两项不是整个构建包的精确增量。

隔离页面采样：Windows / Edge 无头浏览器，1440×900，原图、静态拆层、运行动画分别稳定 1.2 秒后采样 6 秒。
原图：主线程 TaskDuration 约 1.13ms；静态拆层约 0.73ms；动画约 20.96ms。
三种状态均为 0 次 Layout，0ms ScriptDuration；动画有 3 次样式重算，总计约 1.93ms。
绘制合成层数量从 2 增至 12。没有添加 blanket will-change、translateZ 或整个人物 drop-shadow。
这是一组本机短时样本，不能替代真机耗电、真实 GPU 或长时间帧率测试。
完整博客有背景视频与其他既有动效；本次工作期间文章内容同时发生外部改动，因此未把整站前后采样宣称为严格性能对比。
原始采样：.artifacts/character-motion/performance.json
