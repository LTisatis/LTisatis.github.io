# 二次元美化本地版

素材位于 `public/media/`：视频横幅、透明人物、头像、WAAAA! 音频与提取的内嵌封面。原始素材保持不变；人物透明图由 imagegen 处理，轮廓与细节可能与原图略有差异。

- 视频：静音循环，居中缩小至屏宽 64%（最大 1200px，手机 88%），保持完整比例；四周透明渐隐，与粉白渐变背景柔和衔接。鼠标缓动最大约 40px。
- 安奈、索尼娅：左右固定，贯穿视口，高度 112dvh，缓动分别约 65px / 85px；桌面侧边偏移 -24vh，比上一版各向外移动 10vh；手机端向外裁切保留中央阅读区。
- 四层顺序：视频（10）、半透明粉白遮罩（11）、人物（20）、正文与个人卡片（30 以上）。保留深色主题。
- 文章与日常标题及副标题：独立半透明卡片，避免直接叠在视频上；内容卡片 88% 不透明度并加入背景模糊。
- 点击粒子：[canvas-confetti](https://github.com/catdad/canvas-confetti) 1.9.4，14 粒子、粉黄绿紫配色；无点击音效。
- 背景音乐：打开页面尝试自动播放；浏览器拦截时显示一键播放提示。粉色渐变圆形播放按钮，支持暂停、单曲循环、音量记忆、进度拖动和折叠；位于 Swup 替换区域外，常规站内跳转保留播放。
- 暂停动效按钮关闭视差、粒子和视频；系统减少动态效果设置同样生效。

调节人物尺寸、位置、配色和播放器外观：`src/styles/personal.css`。
调节视差与粒子：`src/scripts/atmosphere.ts`。
音乐与人物元素：`src/components/Atmosphere.astro`。
横幅视频：`src/layouts/MainGridLayout.astro`。
