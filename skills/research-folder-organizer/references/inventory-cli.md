# 只读盘点工具约定

仅在使用 `scripts/inventory.py`、解释报告或处理扫描失败时读取。

## 环境与调用

- Python 3.9+，仅使用标准库；不需要联网、账号或额外软件包。
- 输入：一个已存在、可读取的本地目录。目录本身不能是符号链接、Windows junction 或其他 reparse point。
- 输出：标准输出中的 UTF-8 JSON；脚本不创建、修改或移动项目文件，不读取文件内容。将输出保存到文件属于调用方的写入操作；仅只读检查时不要把报告写入被检查项目。
- 路径含空格时加引号，例如 `python "<skill目录>/scripts/inventory.py" "<项目目录>"`。没有 Python 可改用文件工具盘点，保持同等范围说明。

## JSON 字段

| 字段 | 含义 |
| --- | --- |
| `root` | 盘点目录的绝对路径 |
| `generated_at_utc` | 报告生成时间，UTC |
| `complete` | 本次允许扫描的范围是否无错误完成，不代表排除项已经检查 |
| `entries` | 条目列表：相对于根目录的 `path`、`kind`、`size_bytes`、`mtime_utc`、`extension` |
| `skipped` | 按默认规则排除的目录路径与原因 |
| `errors` | 无法读取/扫描的路径、操作和异常消息 |
| `summary` | 条目、普通文件、目录、链接、其他项、普通文件总字节数、排除目录和错误数 |

`kind` 为 `file`、`directory`、`link` 或 `other`。只有普通文件具有字节数和扩展名，其他条目的 `size_bytes` 为 `null`。`summary.directories` 不含根目录及排除目录。修改时间不等于文件创建时间、实验执行时间或结果有效时间。

默认排除 `.git`、`.hg`、`.svn`、`.venv`、`venv`、`node_modules`、`__pycache__` 目录。隐藏文件仍列出。链接和 Windows reparse 条目会以 `link` 列出，不扫描目标；因此不包含目标文件的数量或大小。

## 退出与恢复

| 退出码 | 含义 | 下一步 |
| --- | --- | --- |
| 0 | 指定扫描范围完成 | 查看排除项和链接，再确定候选整理范围 |
| 1 | 部分子项扫描失败 | 保留报告，跳过受影响项；修正具体原因后仅重查必要范围 |
| 2 | 根目录无效、无法扫描或命令用法错误 | 检查路径、权限与参数，修正前不据此整理 |

根目录验证/扫描失败时有 JSON 错误报告；参数解析错误由命令行解析器输出用法提示，不保证产生 JSON。没有输出或 JSON 解析失败时，保留退出码与错误信息，不将其视为空项目。

报告是扫描时的元数据，不是原子快照、内容备份、重复文件结论或路径依赖分析。实际迁移前仍需确认源和目标未变化。大目录的时间与内存开销随条目数增加；不要为解释一个局部问题反复扫描整个项目。
