# 项目目标、思路与交接

替换示例字段，删除不适用栏目；未知内容写“待补充”或“未记录”。已有等价记录时合并，并将模板链接改为项目真实路径。只建立本次需要的记录。

## AGENTS.md：稳定的项目说明

只合并缺失内容，不覆盖现有项目规则。目标和边界不明确时如实填写。

```markdown
# 项目协作说明

## 研究目标与范围
- 研究问题：待补充。
- 当前范围：待补充。

## 从哪里开始
- 先读 handoff.md，了解当前进度和下一步。
- 文献：related_work/；已有方法复现：复现/。
- 自有实验：experiment/；结果：experiment/results.md。
- 测评规则：experiment/evaluation.md。
- 数据位置和处理说明：dataset.md。
- 问题、假说和方法的依据：brainstorm.md。

## 协作表达
- 开始时简要说明这轮要解决的问题与具体任务，围绕已确定目标推进。
- 沿用项目术语；新增概念解释含义，不自造缩写。
- 区分证据、推测与尚未核查的内容，结论指向具体材料。
- 拟改变研究方向或扩大任务范围时，先说明理由并处理所需授权。
- 完成后说明改动和验证结果，更新相关记录及 handoff.md。
```
